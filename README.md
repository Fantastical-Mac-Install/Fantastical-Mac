## Decisions To Make Before You Double-Click Anything

Three answers save you from redoing this later. First: which accounts hold appointments you actually keep, as
opposed to ones you inherited and ignore — a calendar sidebar full of dead subscriptions is the most common
self-inflicted wound. Second: where should a brand-new entry go when you do not specify, because that default
will silently decide hundreds of events. Third: which keys you are prepared to hand over for good, across every
application you run. That combination is the only reason typing beats clicking here, so picking something your
fingers will never locate amounts to disabling the feature on purpose.

## The Setup Pass, Line By Line

- [ ] Install the 4.1.18 build and let the first launch finish before touching anything
- [ ] Add every account that holds real appointments, and skip the ones that do not
- [ ] Untick individual calendars you never want to see, rather than removing the whole account
- [ ] Approve address-book access, otherwise a typed name can never become an invitation
- [ ] Approve the location permission, otherwise a recognised venue has nowhere to come from
- [ ] Set the calendar that receives entries when you do not name one
- [ ] Reserve the global key combination and use it three times immediately
- [ ] Type one disposable appointment, confirm where it landed, then delete it

Do this with something real rather than a test string. Press the combination from inside whatever you are working

## When The Result Is Not What You Typed

| Symptom | Most likely cause |
|---|---|
| Nobody was invited despite being named | Address-book permission was refused early on, or that person has no card in it |
| A venue stayed sitting inside the title as words | Either the location permission is missing, or the place was described too loosely to identify |
| New bookings keep landing somewhere unexpected | Nobody ever changed the account that receives entries by default |
| Pressing the keys accomplishes nothing | Another running program grabbed that combination before this one asked |
| A connected account shows nothing at all | Sign-in succeeded, but its individual calendars are still switched off in the list |
| One meeting is displayed twice over | The same shared calendar reaches you through two different connected accounts |
| Reaching the entry field still feels slow | You are still clicking the icon, which discards the reason the shortcut exists |

Nobody gets the receiving account right on day one, and almost nobody goes back to fix it — they just redirect
event after event for months instead. Spend thirty seconds pointing it wherever the bulk of your bookings
belong and treat the remainder as exceptions. If the wrong person keeps being offered when you type a name,
the correction lives in your contact cards, not in any preference pane here. And if the sidebar has quietly
filled with subscriptions nobody reads, thin it out — a fantastical download mac install stays calm only while
